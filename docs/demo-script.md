# Demo Script

This document will track the repeatable portfolio demo.

## Fixture demo

1. Launch the Flutter app.
2. Select a source and target language pair.
3. Hold push-to-talk.
4. Play the deterministic fixture transcript.
5. Show source and translated captions.
6. Open the latency overlay.
7. Copy the translated text.

Initial fixture language pairs:

- English to Amharic.
- English to French.
- Amharic to English.
